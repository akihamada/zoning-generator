# 図面表記マニュアル / Drawing Notation Standard

本マニュアルは AHA 実施設計図の表記を統一するための基準。スケール別の線の太さ・文字・記号・寸法の扱いを規定する。

## 1. 線の太さ / Line Weights

ペン幅は **mm単位の実寸**。全案件共通。

| ペン | 幅(mm) | 用途 |
|---|---|---|
| 極細 | 0.09 | 補助線、ハッチ、背景参照 |
| 細1 | 0.13 | 通り芯、寸法線、寸法補助線 |
| 細2 | 0.18 | 寸法値・文字（標準）、記号、仕上線 |
| 中1 | 0.25 | 隠れ線、見え掛かり線 |
| 中2 | 0.35 | 一般外形線（1:100 壁等） |
| 太1 | 0.50 | 断面線・主要外形（1:50） |
| 太2 | 0.70 | 断面線（1:100以下）、建物輪郭 |
| 極太 | 1.00 | 図枠境界 |

スケール別の標準割当は Appendix A 参照。

## 2. 文字 / Text

| 用途 | 高さ (mm) | 線の太さ |
|---|---|---|
| 図面タイトル | 5.0〜7.0 | 0.35 |
| サブタイトル／図面名 | 3.5 | 0.25 |
| 注記（標準） | 2.5 | 0.18 |
| 寸法値 | 2.5 | 0.18 |
| 室名 | 3.5 | 0.25 |
| 通り芯番号 | 3.5（○内） | 0.25 |
| 引き出し線テキスト | 2.0〜2.5 | 0.13〜0.18 |

- フォント：ASCII は `Arial` または `Isocpeur`、日本語は `MS ゴシック`
- 英語のみの図面（越側作業用）は `Arial` に統一
- 斜体・太字は原則不使用

## 3. 尺度 / Scale

| 用途 | 推奨スケール |
|---|---|
| 配置図 | 1:500, 1:200 |
| 全体平面／立面／断面 | 1:100（住宅）／1:200（大規模） |
| 部分平面／断面 | 1:50 |
| 矩計図 | 1:30, 1:20 |
| 詳細図 | 1:10, 1:5 |
| 納まり詳細 | 1:2, 1:1 |

- 図面上に **スケールバーを必ず表示**
- NTS（Not To Scale）は原則禁止。どうしても必要な場合は明示

## 4. 寸法 / Dimensions

- 単位：**mm**（記号は省略）
- 精度：1mm単位。5mm丸めは禁止
- 寸法線は途切れさせず、**連続寸法**と**総寸法**を併記
- 寸法値は寸法線の **上** に配置（日本式）
- 矢印：3mm 斜線（tick）または開き矢
- 寸法線の基準は **通り芯または仕上面** から取る（構造芯と仕上面を混在させない）
- スケール依存の見た目調整（寸法文字の手動移動）は最小限に留める

## 5. 記号 / Symbols

| 記号 | 用途 | 備考 |
|---|---|---|
| ○＋数字 | 通り芯番号 | 円径 φ10 (1:100) |
| ▲＋標高値 | レベル記号 | 平面・断面共通 |
| A-A' 矢印 | 断面指示 | 切断方向を明示 |
| 丸＋番号 | 詳細指示 | 上：図面番号／下：シート番号 |
| 四角＋記号 | 建具記号 | AD-01, WD-01 等 |

- 建具記号：`AD-xx`（アルミドア）、`WD-xx`（木製ドア）、`SD-xx`（鋼製ドア）、`AW-xx`（アルミ窓）
- 仕上記号：`F-xx`（床）、`W-xx`（壁）、`C-xx`（天井）
- AHA特殊要素：`3DP-xx`（3Dプリント要素）、`IRR-xx`（異形要素）、`KIN-xx`（キネティック）、`ART-xx`（アート統合）

## 6. ハッチ / Hatching

| 材料 | ハッチパターン | 備考 |
|---|---|---|
| コンクリート | `AR-CONC` | ドット＋三角 |
| 鉄筋コンクリート（RC） | `AR-CONC` ＋ 鉄筋線 | 構造指示時 |
| 鉄骨 | `ANSI31` | 斜線 |
| 木材（製材） | 年輪模様 | 方向性に注意 |
| 断熱材（繊維系） | `BATT` | 向きに注意 |
| 断熱材（発泡系） | 専用パターン | 硬質／発泡で区別 |
| 土（一般） | 点描＋`EARTH` | — |
| 土（3DP） | `EARTH` ＋ 配合記号 | 材料ID併記（例：`AHA-Mix-03`） |

## 7. 凡例・注記 / Legend & Notes

- 各図面シートの **右上** に凡例ブロック
- 注記は **右側縦書きリスト**、番号付き
- 共通注記は `GENERAL NOTES` シートに集約、個別シートからは番号参照
- 和英併記時は同一注記内に `//` で区切って英訳を記載（越側作業用）

## 8. 図枠・表題欄 / Title Block

表題欄には以下を必須記載：

- プロジェクト名（Project Name）
- クライアント名（Client）
- 図面タイトル（Drawing Title）
- 図面番号（ISO 19650準拠、`standards/file-naming.md` 参照）
- 縮尺（Scale）
- 作図者／チェック者／承認者（Drawn / Checked / Approved）
- 発行日（Date）
- Revision（P01／C01...）
- 成熟度コード（S0〜A1）
- 北マーク（配置・平面）

## 9. 越側オペ向け補足 / Notes for VN Operators

- All dimensions in **mm**, no unit symbol
- Do NOT change line weights or color assignment without RFI
- Use `AHA_LayerTemplate.dwt` / `AHA_RevitTemplate.rte` as starting point
- If unsure about symbol or notation, raise an RFI — do not improvise
- Hatch orientation (wood grain, fiber insulation) is meaningful — preserve direction from reference
