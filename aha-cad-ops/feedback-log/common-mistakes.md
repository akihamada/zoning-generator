# 越側CADオペ頻出ミス集 / Common Mistakes Log

越側CADオペの作業で繰り返し発生した問題を類型化して記録。各ミスは対応するチェックリスト項目へ反映し、再発を防ぐ。

## 運用ルール

1. ミス発見時は **即日** 本ファイルに追記
2. 2回目以降の再発時は `頻度` を更新し、対応する L1〜L4 項目を見直し
3. 対策をチェックリスト項目に反映した場合は、反映先（L何の何番）を明記
4. 月次で PM が棚卸し、上位頻発項目を越側にフィードバック

## 記入フォーマット / Entry Format

```
### [YYYY-MM-DD] <案件コード> — <ミスのタイトル>

**カテゴリ**：<命名規則 / 寸法 / 線 / 図面整合 / LOD / AHA特性 / その他>
**頻度**：<初発 / 2回目 / 恒常>
**発見段階**：<L1 / L2-30 / L2-60 / L2-90 / L3 / 出図後>

**事象**：
（何が起きたか、簡潔に）

**原因**：
（直接原因・根本原因）

**影響**：
（工数・品質・スケジュール）

**対策**：
（その場の対応 / 恒久対策）

**チェックリスト反映**：
- [ ] L<X>-<項目> に追加／修正
- [ ] `standards/<file>.md` に追記
```
