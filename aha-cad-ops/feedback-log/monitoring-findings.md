# 現場・施工段階フィードバック / Field Monitoring Findings

実施図面を元に施工が進んだ結果、現場から返ってきたフィードバックを記録。図面品質の底上げ・次案件での先回り対応に活用する。

## 運用ルール

1. 現場監督・施工業者からの指摘は **受領後2営業日以内** に本ファイルへ記録
2. 図面上の原因分析は PM と設計リーダーで合議
3. 対策は以下3つのいずれかに反映：
   - `checklists/L<X>.md` にチェック項目追加
   - `detail-library/<ID>/notes.md` に注意点追記
   - `standards/<file>.md` に規約更新
4. 反映先を記録欄に必ず明記

## 記入フォーマット / Entry Format

```
### [YYYY-MM-DD] <案件コード> — <発見事項タイトル>

**発見元**：<現場監督 / 施工業者 / 施主 / 設計者現場確認>
**発見段階**：<着工前 / 基礎 / 躯体 / 仕上 / 竣工後>
**該当要素**：<通常 / 3DP / IRR / KIN / SEN / ART / HIS>

**事象**：
（現場で何が起きたか）

**図面上の原因**：
（図面の不備・曖昧さ・指示不足）

**現場対応**：
（その場で何が行われたか）

**設計意図との乖離**：
（仕上がりが設計意図からどれだけ離れたか）

**対策反映**：
- [ ] `checklists/L<X>.md` へ項目追加
- [ ] `detail-library/<ID>/notes.md` へ注意点追記
- [ ] `standards/<file>.md` へ規約更新
```
