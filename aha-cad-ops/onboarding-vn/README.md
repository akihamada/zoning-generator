## Key Principles (Read First)

1. **Never improvise on standards.** If unsure, raise an RFI — do not invent.
2. **One task = one task brief.** You always receive a written brief. If you don't, ask for it.
3. **Raise questions early.** An RFI is faster than guessing wrong and redoing work.
4. **Self-check before handoff.** Complete the self-check section of the task brief before returning.
5. **Respect originals.** Do not modify Rhino master files. Do not add shared parameters without approval.
