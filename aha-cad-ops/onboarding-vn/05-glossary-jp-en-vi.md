# 05 — Glossary JP / EN / VI

Working glossary for common architectural and CAD terms used between Japan and Vietnam. Vietnamese is for reference; working language on drawings and task briefs is **English**.

Missing term? Raise with Japan PM — we add to this file.

## General

| 日本語 | English | Tiếng Việt |
|---|---|---|
| 実施設計 | Detailed Design (DD) | Thiết kế kỹ thuật |
| 基本設計 | Schematic Design (SD) | Thiết kế cơ sở |
| 施工図 | Shop drawing | Bản vẽ thi công |
| 竣工図 | As-built drawing | Bản vẽ hoàn công |
| 指示書 | Task brief / Instruction sheet | Phiếu chỉ dẫn công việc |
| 質問票 | RFI — Request for Information | Phiếu yêu cầu thông tin |
| 議事録 | Meeting minutes | Biên bản họp |
| 出図 | Drawing issue | Phát hành bản vẽ |
| 改訂 | Revision | Chỉnh sửa |
| 縮尺 | Scale | Tỉ lệ |
| 凡例 | Legend | Chú giải |
| 注記 | Notes / Annotation | Ghi chú |
| 寸法 | Dimension | Kích thước |
| 通り芯 | Grid line | Trục |
| 階高 | Floor-to-floor height | Chiều cao tầng |
| 軒高 | Eave height | Chiều cao mái hiên |
| 最高高さ | Maximum building height | Chiều cao tối đa |
| レベル | Level (elevation) | Cao độ |
