# L2: 実施設計 30/60/90% マイルストーンチェック

**階層** / Level: **L2**
**実施タイミング** / Timing: 実施設計進捗 30% / 60% / 90% 時点
**責任者** / Owner: 日本側PM（合議）
**所要** / Duration: 各回 半日〜1日

各マイルストーンでのゲート判定。該当項目の **80%以上達成** を次工程進行の条件とする。未達項目は明示・期限付きでアクション化する。

---

## 30% マイルストーン — 骨格確定 / Framework Lock

この時点で **図面フレームワーク** が固まっている状態を目指す。

### 図面構成 / Drawing Structure
- [ ] 【越側オペ／30%時点】図面リスト（Drawing List）の初版が作成済み
- [ ] 【越側オペ／30%時点】全シートの図枠・表題欄・シート番号が配置済み
- [ ] 【越側オペ／30%時点】`standards/file-naming.md` に準拠したファイル命名
- [ ] 【PM／30%時点】`templates/drawing-list/` 準拠で抜け漏れ確認

### 平面・通り芯 / Plans & Grid
- [ ] 【越側オペ／30%時点】全階平面の通り芯・外壁線が確定
- [ ] 【PM／30%時点】構造通り芯と意匠通り芯の整合（構造設計者にも確認）
- [ ] 【越側オペ／30%時点】主要開口の位置・寸法が配置済み

### 断面・立面 / Sections & Elevations
- [ ] 【越側オペ／30%時点】主要断面（最低2方向）の骨格線
- [ ] 【越側オペ／30%時点】全立面の外形線・開口位置
- [ ] 【越側オペ／30%時点】階高・軒高・最高高さの寸法

### 注記・凡例 / Notes & Legend
- [ ] 【PM／30%時点】General Notes シートの下書き
- [ ] 【越側オペ／30%時点】共通凡例シート（記号・ハッチ・線種）

### AHA特殊要素 / AHA-Specific
- [ ] 【設計リーダー／30%時点】3DP／IRR／KIN／ART 要素の配置ゾーンが明示
- [ ] 【設計リーダー／30%時点】Rhino 原型ファイルの所在・バージョンが記録済み

**30% ゲート判定**：上記項目の **80%以上 PASS** → 60% へ進行可

---

## 60% マイルストーン — 情報密度確保 / Information Density

この時点で **寸法・仕様・建具・仕上げ** が一通り埋まっている状態。

### 寸法・仕様 / Dimensions & Specifications
- [ ] 【越側オペ／60%時点】全平面・断面の寸法記入完了
- [ ] 【越側オペ／60%時点】連続寸法＋総寸法の整合確認（チェーン閉合）
- [ ] 【越側オペ／60%時点】レベル・高さ記号の網羅

### スケジュール（表） / Schedules
- [ ] 【越側オペ／60%時点】建具表（ドア・窓）の初版
- [ ] 【越側オペ／60%時点】仕上表（床・壁・天井）の初版
- [ ] 【越側オペ／60%時点】面積表（用途別・階別）の初版
- [ ] 【越側オペ／60%時点】機器表の初版
- [ ] 【PM／60%時点】表と図の件数整合（ドア数・窓数の一致）

### 詳細・ディテール / Details
- [ ] 【越側オペ／60%時点】ディテール参照マーカー（丸囲み番号）が全シートに配置
- [ ] 【越側オペ／60%時点】矩計図（1:30 or 1:20）の初版
- [ ] 【越側オペ／60%時点】主要ディテール（開口部・軒先・笠木・基礎）の初版
- [ ] 【設計リーダー／60%時点】`detail-library/` からの流用可否が判定済み

### 他工種調整 / Consultant Coordination
- [ ] 【PM／60%時点】構造との整合レビュー実施（議事録あり）
- [ ] 【PM／60%時点】設備（M/E/P）との整合レビュー実施
- [ ] 【PM／60%時点】1回目のクラッシュ検出実行、Critical クラッシュ対応計画あり

### AHA特殊要素 / AHA-Specific
- [ ] 【設計リーダー／60%時点】L4 チェックリストの該当項目が60%完了
- [ ] 【設計リーダー／60%時点】土系3DP 部材の材料配合・層厚・養生が仕様書に記載
- [ ] 【設計リーダー／60%時点】キネティック・アート要素のアーティスト／エンジニア連絡先確定

**60% ゲート判定**：上記項目の **80%以上 PASS** → 90% へ進行可

## 90% マイルストーン — 出図準備完了 / Issue-Ready

この時点で **L3（出図前最終チェック）に入れる** 状態。

### ディテール完了 / Detail Completion
- [ ] 【越側オペ／90%時点】全ディテール参照の実体化完了（未解決の "SIM" なし）
- [ ] 【設計リーダー／90%時点】AHA特殊要素の詳細図が全て存在
- [ ] 【設計リーダー／90%時点】接合部・取合い部の寸法・納まりが明示

### 仕様書との整合 / Specification Consistency
- [ ] 【PM／90%時点】仕様書と図面の材料名称・番号が一致
- [ ] 【PM／90%時点】建具表と仕様書の金物リストが一致

### 最終クラッシュ検出 / Final Clash Detection
- [ ] 【PM／90%時点】最終クラッシュ検出実行、**Critical クラッシュ 0**
- [ ] 【PM／90%時点】Major クラッシュの対応記録

### クライアント事前レビュー / Client Pre-Review
- [ ] 【PM／90%時点】施主との事前レビュー実施、指摘対応完了
- [ ] 【PM／90%時点】未決議事項（open items）の残件確認

### 出図パッケージ準備 / Issue Package Prep
- [ ] 【越側オペ／90%時点】PDF 出力設定確認（ペン割当・用紙サイズ）
- [ ] 【越側オペ／90%時点】DWG / RVT のファイル整理（不要レイヤ・ワークセット削除）
- [ ] 【越側オペ／90%時点】ファイル命名が `standards/file-naming.md` 準拠

**90% ゲート判定**：上記項目の **100% PASS** → L3（出図前最終チェック）へ
