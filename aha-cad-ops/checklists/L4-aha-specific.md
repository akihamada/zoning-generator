# L4: AHA特有要素チェック / AHA-Specific Items Check

**階層** / Level: **L4**
**実施タイミング** / Timing: 該当要素を含む案件の実施設計全段階（L2の60%・90%、L3で必須確認）
**責任者** / Owner: 設計リーダー（PMと合議）
**前提** / Prerequisite: 本チェックリストは案件に **該当する要素のみ** を抜粋して使用する

AHA 案件は一品生産性が高く、通常事務所の標準チェックでは品質を担保できない特殊要素を含む。本リストは以下6カテゴリを対象：

1. 土系3Dプリント（3DP）
2. 異形形態（IRR）
3. キネティック機構（KIN）
4. センサー統合（SEN）
5. デジタルアート統合（ART）
6. 歴史建築保存・修復（HIS）

---

## 1. 土系3Dプリント / Soil 3D Printing (3DP)

### 材料・配合 / Material & Mix
- [ ] 【設計リーダー／60%時点】材料配合（土質・バインダー・水分率）が仕様書に記載
- [ ] 【設計リーダー／60%時点】**酸化マグネシウム系バインダーの配合比** が明記
- [ ] 【設計リーダー／60%時点】繊維補強材（種類・長さ・混入率）が明記
- [ ] 【設計リーダー／60%時点】試験体試験結果が参照されている（**材料性能判断は専門家確認を促す**）
- [ ] 【PM／60%時点】材料サプライヤー・ロット管理方針が確認済み

### 印字・幾何 / Printing & Geometry
- [ ] 【設計リーダー／60%時点】層厚（layer height）が図面・仕様書に記載
- [ ] 【設計リーダー／60%時点】印字方向（垂直／水平／傾斜）が明記
- [ ] 【越側オペ／60%時点】Gコード出力を想定した幾何精度で作図
- [ ] 【設計リーダー／90%時点】オーバーハング限界を超えていないか確認
- [ ] 【設計リーダー／90%時点】印字機ビルドボリューム内に収まる分割計画

### 養生・接合 / Curing & Joints
- [ ] 【設計リーダー／60%時点】養生期間・温湿度条件が仕様書に記載
- [ ] 【設計リーダー／90%時点】他部材との接合ディテール（アンカー・金物）あり
- [ ] 【設計リーダー／90%時点】防水・止水の取り合いが明示

### 構造的位置づけ / Structural Role
- [ ] 【構造設計者】耐力／非耐力の区分が構造設計者から書面で回答
- [ ] 【構造設計者】荷重条件・許容応力度が書面で共有
- [ ] 【PM】**構造設計者の確認なしに耐力部材として図面化していない**

---

## 2. 異形形態 / Irregular Geometry (IRR)

### Rhino 原型管理 / Rhino Master File Management
- [ ] 【設計リーダー／キックオフ】Rhino 原型ファイルの **マスターパス** が固定
- [ ] 【設計リーダー／60%時点】バージョン管理（日付＋リビジョン名）
- [ ] 【設計リーダー／90%時点】最終版の Rhino ファイルハッシュを仕様書に記載
- [ ] 【設計リーダー】原型編集権限者がPMと合意（**無断改変禁止**）

### Rhino ↔ Revit ワークフロー
- [ ] 【越側オペ／60%時点】Rhino → Revit 取込み手法が指定（SAT / DirectShape / Rhino.Inside）
- [ ] 【越側オペ／60%時点】メッシュトポロジー健全性確認（開き・重複面・法線反転なし）
- [ ] 【越側オペ／90%時点】Revit 取込み後のジオメトリ精度が Rhino 原型と一致（ずれ許容値を案件別に規定）
- [ ] 【越側オペ】**Revit Edit Family でのメッシュ編集をしていない**

### 製作対応 / Fabrication
- [ ] 【設計リーダー／90%時点】製作分割計画（パネル割・搬入寸法）
- [ ] 【設計リーダー／90%時点】接合部ディテール（金物・公差）
- [ ] 【設計リーダー／90%時点】Fabrication documents（CNC/NC/Gコード）の出力元ファイル明示

---

## 3. キネティック機構 / Kinetic Mechanisms (KIN)

### 機構設計 / Mechanism Design
- [ ] 【機構エンジニア／60%時点】機構図（可動範囲・回転軸・駆動機構）が存在
- [ ] 【機構エンジニア／60%時点】駆動源（モーター・アクチュエータ）の型番・仕様
- [ ] 【機構エンジニア／90%時点】干渉チェック（可動時の他部材との干渉）

### 電源・制御 / Power & Control
- [ ] 【設備／60%時点】電源容量・電圧・引込経路が設備図に反映
- [ ] 【設備／60%時点】制御信号（DMX / Art-Net / OSC / MQTT 等）のプロトコル確定
- [ ] 【設備／60%時点】コントローラ設置場所・点検口
- [ ] 【設備／90%時点】非常停止・安全回路（**安全回路は専門家確認を促す**）

### 施工・保守 / Installation & Maintenance
- [ ] 【設計リーダー／90%時点】点検口・保守スペースの確保
- [ ] 【設計リーダー／90%時点】試運転（commissioning）責任者・手順書
- [ ] 【設計リーダー／90%時点】保守周期・消耗部品リスト

---

## 4. センサー統合 / Sensor Integration (SEN)

- [ ] 【設備／60%時点】センサー種別・型番・設置位置が平面図に記載
- [ ] 【設備／60%時点】配線経路（電源・データ）が設備図に反映
- [ ] 【設備／60%時点】データ収集先（エッジ／クラウド）の指定
- [ ] 【設備／60%時点】電源方式（PoE / AC / DC / バッテリー）
- [ ] 【設備／90%時点】防水・防塵等級（IP rating）が仕様書に記載
- [ ] 【設備／90%時点】キャリブレーション手順・担当
- [ ] 【PM】個人情報・プライバシー配慮（カメラ系センサー時、**法務確認を促す**）

---

## 5. デジタルアート統合 / Digital Art Integration (ART)

### アーティスト・エンジニア連絡 / Artist & Engineer Coordination
- [ ] 【PM／キックオフ】アーティスト・制作エンジニアの連絡先が確定
- [ ] 【PM／キックオフ】著作権・権利関係の契約書確認（**法務確認を促す**）
- [ ] 【PM／60%時点】アート側の仕様書（作品解像度・色域・音量等）を受領

### インターフェース / Interface
- [ ] 【設備／60%時点】映像インターフェース（HDMI / SDI / NDI 等）
- [ ] 【設備／60%時点】音響インターフェース・スピーカー配置
- [ ] 【設備／60%時点】照明連動（DMX 等）
- [ ] 【設備／60%時点】ネットワーク・帯域要件

### 試運転・運用 / Commissioning & Operation
- [ ] 【PM／90%時点】commissioning スケジュール（アーティスト立会い日程）
- [ ] 【PM／90%時点】運用マニュアル（起動・停止・障害対応）
- [ ] 【PM／90%時点】長期運用時のコンテンツ更新方法

---

## 6. 歴史建築保存・修復 / Historic Preservation (HIS)

（対象案件：旧高岡共立銀行等）

### 既存調査 / Existing Survey
- [ ] 【PM／キックオフ前】既存測量（3Dスキャン／実測）完了、データ格納
- [ ] 【PM／キックオフ前】既存図面（オリジナル・過去改修履歴）収集
- [ ] 【PM／キックオフ前】劣化調査・構造診断結果（**専門家確認を促す**）
- [ ] 【PM／キックオフ前】**文化財指定区分の確認**（**法令上の制約確認を促す**）

### 保存区分の図示 / Preservation Zoning
- [ ] 【設計リーダー／30%時点】保存／改修／撤去の区分が図面に明示
- [ ] 【設計リーダー／60%時点】保存部位の許容介入範囲が仕様書に記載
- [ ] 【設計リーダー／90%時点】既存材料と新規材料の取合い部ディテール

### 許容乖離 / Dimensional Tolerance
- [ ] 【設計リーダー／60%時点】既存部の寸法乖離（実測値とオリジナル図面の差）が記録
- [ ] 【設計リーダー／60%時点】新規部の許容誤差が仕様書に記載
- [ ] 【越側オペ／60%時点】既存測量ベースの作図（理想寸法からの作図ではない）

### 可逆性・保存倫理 / Reversibility
- [ ] 【設計リーダー／90%時点】新規介入の **可逆性**（将来撤去可能性）検討記録
- [ ] 【設計リーダー／90%時点】保存材料への不可逆処理（塗装剥離・固定等）の必要性検討
