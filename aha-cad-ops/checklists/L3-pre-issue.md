# L3: 出図前最終チェック / Pre-Issue Final Check

> **一言で** / TL;DR
> 出図 2〜3日前の最終 QC。**全項目 PASS** が出図条件。1項目でも NG なら出図延期。
>
> **誰が主担当**：日本側PM（最終サイン）／越側オペ（セルフチェック）
> **関連**：`checklists/L2-milestone-30-60-90.md`（前提：90% PASS）／`checklists/L4-aha-specific.md`（AHA要素の全PASS確認）

**階層** / Level: **L3**
**実施タイミング** / Timing: 出図の 2〜3営業日前
**責任者** / Owner: 日本側PM（最終サイン）
**所要** / Duration: 半日〜1日

出図直前の最終QC。**L2 の 90% マイルストーンをPASSしていること** が前提。本チェックリストは **全項目 PASS** を出図条件とする。

---

## 1. 線・ペン / Lines & Pens

- [ ] 【越側オペ／出図3日前】`standards/drawing-notation.md` のペン割当に準拠
- [ ] 【越側オペ／出図3日前】全シートで線の太さが統一（特にスケール差のある図面間）
- [ ] 【越側オペ／出図3日前】色従属プロットスタイル（CTB）が AHA 標準
- [ ] 【PM／出図2日前】PDFプレビューで線の太さを目視確認

## 2. 寸法 / Dimensions

- [ ] 【越側オペ／出図3日前】全寸法に単位欠落なし（mm単位、記号省略）
- [ ] 【越側オペ／出図3日前】連続寸法のチェーン閉合（総寸法＝個別寸法合計）
- [ ] 【越側オペ／出図3日前】寸法抜け（主要開口・階高・軒高・最高高さ）なし
- [ ] 【越側オペ／出図3日前】寸法の二重記入なし
- [ ] 【PM／出図2日前】寸法基準（通り芯／仕上面）の混在なし

## 3. 表題欄・図面番号 / Title Block

- [ ] 【越側オペ／出図3日前】全シートの表題欄が埋まっている（プロジェクト名・クライアント・縮尺）
- [ ] 【越側オペ／出図3日前】図面番号が `standards/file-naming.md` 準拠
- [ ] 【越側オペ／出図3日前】作図者・チェック者・承認者欄が記入済み
- [ ] 【越側オペ／出図3日前】発行日・Revision（P01等）・成熟度コード（S2／A1等）記入済み
- [ ] 【越側オペ／出図3日前】北マーク（配置・平面）の向きが正しい

## 4. 相互参照 / Cross-References

- [ ] 【越側オペ／出図3日前】ディテール参照マーカー（丸囲み）が **全て解決**（"SIM"・未定義なし）
- [ ] 【越側オペ／出図3日前】断面指示マーカー（A-A' 等）と実際の断面図が対応
- [ ] 【越側オペ／出図3日前】建具記号・仕上記号が表と一致
- [ ] 【PM／出図2日前】図面相互の整合（平面の開口と立面の開口が一致）

## 5. スケジュール整合 / Schedule Consistency

- [ ] 【越側オペ／出図3日前】建具表のドア件数 = 平面図のドア件数
- [ ] 【越側オペ／出図3日前】建具表の窓件数 = 立面図・平面図の窓件数
- [ ] 【越側オペ／出図3日前】仕上表と平面図・断面図の記号が一致
- [ ] 【越側オペ／出図3日前】面積表の合計 = 平面図からの計算値
- [ ] 【PM／出図2日前】機器表と設備図の機器リストが一致

## 6. 改訂管理 / Revision Control

- [ ] 【越側オペ／出図3日前】改訂クラウド・改訂三角記号が全変更箇所に配置
- [ ] 【越側オペ／出図3日前】改訂履歴表（Rev Table）が更新済み
- [ ] 【PM／出図2日前】前回出図版との差分レビュー実施（議事録あり）

## 7. PDF 出力 / PDF Export

- [ ] 【越側オペ／出図2日前】用紙サイズ（A1/A2/A3）指定通り
- [ ] 【越側オペ／出図2日前】ページ順序が図面リスト順と一致
- [ ] 【越側オペ／出図2日前】解像度・プロットスタイルが AHA 標準
- [ ] 【越側オペ／出図2日前】PDF の文字が検索可能（OCR化不要なベクター出力）
- [ ] 【PM／出図1日前】最終PDFを全ページ目視レビュー
