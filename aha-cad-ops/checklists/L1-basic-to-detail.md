# L1: 基本設計 → 実施設計 移行時チェック

**階層** / Level: **L1**
**実施タイミング** / Timing: 基本設計完了〜実施設計着手時（案件ごとに1回）
**責任者** / Owner: 日本側PM
**所要** / Duration: 1〜2日（案件規模に応じて）

基本設計から実施設計へ移行する際に、情報の固定・前提の明示・体制整備を行う。ここが曖昧なまま実施に入ると越側オペへの指示が不安定になり、手戻りが雪だるま式に増える。

---

## 1. スコープ凍結 / Scope Freeze

- [ ] 【PM／基本完了時】基本設計図一式が **施主承認済み** であることを文書確認
- [ ] 【PM／キックオフ前】延床・階数・主要用途に **変更がないこと** をメール等で再確認
- [ ] 【PM／キックオフ前】施主未決事項リスト（open items）を文書化し、決定期限を設定
- [ ] 【PM／キックオフ前】**設計変更の受付ルール** を施主と合意（書面／WBS反映）
- [ ] 【設計リーダー／キックオフ前】デザインインテント文書化（Hyper Naturalism / Computing Wildness の具体的適用箇所）

## 2. 入力資料の固定 / Input Material Freeze

- [ ] 【PM／キックオフ前】敷地測量図（最新）を `projects/[案件コード]/01_Site/` に格納
- [ ] 【PM／キックオフ前】地盤調査報告書の有無を確認、あれば格納
- [ ] 【PM／キックオフ前】既存建物調査資料（歴史建築リノベ時）を格納・参照可能化
- [ ] 【PM／キックオフ前】都市計画・法規チェック結果を文書化（**法規判断は専門家確認を促す**）
- [ ] 【PM／キックオフ前】設備インフラ条件（上下水・電力・ガス・通信）を文書化
- [ ] 【PM／キックオフ前】参照過去案件コードを明示（ディテール流用元）

## 3. 構造連携 / Structural Coordination

- [ ] 【PM／キックオフ前】構造設計者アサインの確認
- [ ] 【構造／キックオフ週】構造グリッド・通り芯を確定
- [ ] 【構造／キックオフ週】主要断面（柱寸法・梁せい・スラブ厚・基礎形式）の初期値を共有
- [ ] 【構造／2週以内】異形形態の構造成立性を構造設計者と確認（該当時）
- [ ] 【構造／2週以内】土系3Dプリント部材の構造的位置づけ（耐力／非耐力）を書面で回答
- [ ] 【PM】構造⇔意匠の整合確認サイクル（週次）を設定

## 4. 設備連携 / MEP Coordination

- [ ] 【PM／キックオフ前】M・E・P 各設計者アサインの確認
- [ ] 【MEP／2週以内】主要機器リスト・容量の初期値を受領
- [ ] 【MEP／2週以内】PS・DS・天井懐の必要高さを確認
- [ ] 【MEP／2週以内】キネティック／センサー／アート要素の電源・データ要件を設備側に共有
- [ ] 【PM】クラッシュ検出の実施頻度・ツール（Navisworks / BIM 360 等）を決定

## 5. LOD 遷移 / LOD Transition

- [ ] 【PM】`templates/lod-matrix/` をコピーし案件別LOD表を作成
- [ ] 【PM】要素ごとの目標LODを明示（実施着手時は300、中間60%で350、出図前400）
- [ ] 【PM】**AHA特殊要素（3DP／IRR／KIN／SEN／ART／HIS）は通常より1段階上のLODを設定**
- [ ] 【PM】LOD表を越側オペと共有、指示書にリンク

## 6. 体制・ツール整備 / Team & Tools

- [ ] 【PM】`projects/[案件コード]/` ディレクトリを作成、初期ファイルセット配置
- [ ] 【PM】Revit / AutoCAD テンプレート（`AHA_RevitTemplate.rte` / `AHA_LayerTemplate.dwt`）から案件ファイルを生成
- [ ] 【PM】ファイル命名規則の案件コードを `projects/[案件コード]/CLAUDE.md` に記載
- [ ] 【PM】Slack チャンネル（日越合同）を開設、固定メンバーをアサイン
- [ ] 【PM】Notion / Drive の権限設定・フォルダ構成を確認
- [ ] 【PM】キックオフミーティングを日越両方で実施（議事録を `projects/[案件コード]/` に保存）
- [ ] 【PM／越側オペ】本チェックリスト L1 の完了サインを取得

## 7. AHA特性の明示 / AHA-Specific Items

- [ ] 【設計リーダー】本案件に含まれるAHA特殊要素を明示（3DP／IRR／KIN／SEN／ART／HIS のいずれか／なし）
- [ ] 【設計リーダー】L4 チェックリストの該当セクションを案件別に抜粋・越側へ事前共有
- [ ] 【設計リーダー】参考過去案件（類似要素を持つ）を `feedback-log/` および `detail-library/` から抽出し共有
